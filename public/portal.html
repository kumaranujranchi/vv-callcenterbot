🛡️ Windows Security Warning (SmartScreen) Resolution Trust & Security

Jab aap portal se direct `.exe` installer download karte hain, to Windows "Windows protected your PC / Unknown Publisher" ki security warning dikha sakta hai. Yeh kisi bhi naye internal desktop application ke liye Windows Defender ka normal behavior hai.

1. User Direct Run (SmartScreen Bypass) Warning screen aane par "More info" (Jaankari) par click karein → Phir "Run anyway" (Fir bhi chalayein) select karein. Installation turant shuru ho jayegi.
2. IT Admin PowerShell Unblock (Automatic) System admin 1-line command se block remove kar sakte hain: Unblock-File -Path "$env:USERPROFILE\Downloads\CallCenterCopilot-Setup.exe"
